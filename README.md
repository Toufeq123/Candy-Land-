# Candy Cash Match

Original mobile-friendly match-3 web game with five levels.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and `game.js` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the published URL shown by GitHub Pages.

## Telegram Mini App
Use the GitHub Pages HTTPS URL as the Mini App URL in BotFather. The Telegram Web App script is already included.

No copyrighted Candy Crush artwork or branding is included.
